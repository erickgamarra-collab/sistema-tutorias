PASOS PARA PUBLICAR ESTE PROYECTO EN GITHUB

1. Crea en GitHub un repositorio vacío llamado: sistema-tutorias
   No agregues README, .gitignore ni licencia desde GitHub porque el proyecto ya los contiene.

2. Abre una terminal dentro de esta carpeta.

3. Cambia el remoto por tu URL real:
   git remote add origin https://github.com/TU_USUARIO/sistema-tutorias.git

4. Renombra la rama principal si deseas usar main:
   git branch -M main

5. Sube todos los commits existentes:
   git push -u origin main

6. Copia la URL del repositorio y reemplaza:
   PEGAR_AQUI_URL_DEL_REPOSITORIO
   tanto en README.md como en el PDF final.

7. Verifica la URL en una ventana privada/incógnito.
