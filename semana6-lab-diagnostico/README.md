# Semana 6 — Código heredado y Ae5

Proyecto **independiente** dentro del repositorio `sistema-tutorias`, basado en el caso proporcionado por la guía de la Semana 6, **no** en las clases ya refactorizadas de Ae3/Ae4. El objetivo es preservar los contratos NORMAL=40, VIP=34, entradas inválidas=0 y el orden de las salidas por consola.

## Requisitos

JDK 21, Maven y Git.

Desde la raíz del repositorio:

```bash
mvn -f semana6-lab-diagnostico/pom.xml clean compile
mvn -f semana6-lab-diagnostico/pom.xml clean test
java -cp semana6-lab-diagnostico/target/classes edu.uees.refactor.app.Main
```

El código inicial se conserva en el primer commit de la rama `semana6-labs-ae5`. La ejecución de ejemplo debe mostrar las dos líneas de consola, estado CONFIRMADA y total 34.0. Los archivos de diagnóstico, pruebas y Ae5 se incorporan en commits posteriores, por separado.
